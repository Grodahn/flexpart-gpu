# NOTICE - FLEXPART-GPU

## Project origin

`flexpart-gpu` is a standalone Rust/WebGPU reimplementation of FLEXPART components.
The scientific concepts, physical schemes, and part of the algorithmic structures
originate from the upstream FLEXPART project.

This repository is an independent and unofficial effort and is not affiliated with,
or endorsed by, the official FLEXPART development team. FLEXPART 11.1 is used as a
reference oracle for explicitly scoped compatibility and validation work; this does
not imply that the project as a whole has achieved scientific parity with upstream.

## Upstream reference
